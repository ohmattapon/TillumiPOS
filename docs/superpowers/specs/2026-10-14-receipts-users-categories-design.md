# ใบเสร็จ การพิมพ์ และหน้าจัดการที่ขาด

สถานะ: ร่างสำหรับลงมือทำ · roadmap ข้อ 11 · branch `ohmattpon/receipts-users-categories` (ต่อจาก `ohmattpon/cash-shifts`)

## เป้าหมาย

ร้านใช้งานจริงได้โดยไม่ต้องแตะ API ตรง: เจ้าของจัดการผู้ใช้และหมวดหมู่จากหน้าเว็บ ใบเสร็จพิมพ์ออกเครื่อง thermal ได้พอดีกระดาษ เป็นใบกำกับภาษีอย่างย่อเมื่อร้านจด VAT และใบเก่าไม่เปลี่ยนเมื่อร้านแก้ชื่อหรือที่อยู่

## การตัดสินใจ

| เรื่อง | ตัดสินใจ | เหตุผล |
|---|---|---|
| การพิมพ์ | พิมพ์ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์ ด้วย CSS ขนาดกระดาษ 58 หรือ 80 มม. | ใช้ได้กับเครื่อง thermal ทุกยี่ห้อที่มี driver ไม่ต้องมีโปรแกรมเสริม การสั่ง ESC/POS ตรงหรือเปิดลิ้นชักเป็นของหลังรุ่นแรก |
| ขนาดกระดาษ | ตั้งระดับร้านในหน้าตั้งค่า (`receiptPaperMm`: 58 หรือ 80, ค่าเริ่มต้น 80) | เครื่องพิมพ์ในร้านเดียวกันมักเป็นรุ่นเดียว |
| ข้อความท้ายใบเสร็จ | ตั้งได้ในหน้าตั้งค่า (`receiptFooter`, ว่างได้, ไม่เกิน 200 ตัว) | เช่น "ขอบคุณที่ใช้บริการ" หรือเงื่อนไขการคืนสินค้า |
| ใบกำกับภาษีอย่างย่อ | หัวใบเป็น "ใบกำกับภาษีอย่างย่อ" เมื่อบิลมีเลขผู้เสียภาษีและคิด VAT ไม่เช่นนั้นเป็น "ใบเสร็จรับเงิน" | ตามมาตรา 86/6: ต้องมีคำว่าใบกำกับภาษีอย่างย่อ ชื่อและเลขผู้เสียภาษีของผู้ขาย เลขที่ รายการ ราคาที่ระบุว่ารวม VAT และวันที่ |
| ข้อมูลร้านบนบิล | เก็บชื่อร้าน เลขผู้เสียภาษี ชื่อสาขา ที่อยู่ และเบอร์โทร ลงบิลตอนขาย | ใบเก่าต้องไม่เปลี่ยนเมื่อร้านย้ายที่หรือเปลี่ยนชื่อ บิลเก่าที่ไม่มี snapshot แสดงข้อมูลปัจจุบันเหมือนเดิม |
| หน้าผู้ใช้ | เจ้าของเท่านั้น: รายการ เพิ่ม แก้ชื่อ/บทบาท/สาขา ปิดใช้งาน ตั้งรหัสผ่านใหม่ | API มีครบแล้ว ชื่อผู้ใช้แก้ไม่ได้ |
| หน้าหมวดหมู่ | เจ้าของเท่านั้น: รายการ เพิ่ม เปลี่ยนชื่อ ลำดับ ปิดใช้งาน | API มีครบแล้ว ลบไม่ได้ (ปิดใช้งานแทน) |

## ข้อมูลและ API

- `sales`: เพิ่ม `shop_name`, `shop_tax_id`, `branch_name`, `shop_address`, `shop_phone` แบบ nullable คำตอบของบิลเพิ่มช่องเหล่านี้ (เพิ่มอย่างเดียว ไม่กระทบผู้ใช้ API เดิม)
- `shop_settings`: เพิ่ม `receipt_paper_mm` (58|80) และ `receipt_footer`
- ไม่มีเส้นทางใหม่: หน้าผู้ใช้ใช้ `/users` หน้าหมวดหมู่ใช้ `/catalog/categories`

## นอกขอบเขต

ESC/POS ตรง, เปิดลิ้นชักเงินสด, พิมพ์ใบสั่งครัว, ใบกำกับภาษีเต็มรูป, โลโก้บนใบเสร็จ, ลบผู้ใช้หรือหมวดหมู่

## เสร็จเมื่อ

- เจ้าของเพิ่มพนักงาน ย้ายสาขา ปิดใช้งาน และตั้งรหัสผ่านใหม่ได้จากหน้าเว็บ
- เจ้าของเพิ่มและจัดลำดับหมวดหมู่ได้จากหน้าเว็บ
- ใบเสร็จของบิลเก่าไม่เปลี่ยนหลังแก้ชื่อร้านหรือที่อยู่สาขา
- ใบเสร็จพิมพ์พอดีกระดาษ 58 และ 80 มม. และขึ้นหัว "ใบกำกับภาษีอย่างย่อ" ตามเงื่อนไข
- `typecheck`, `test`, `lint`, `openapi:check` และ `e2e` ผ่าน
