# แผนย้าย QR จาก SCB ไป KBank (แทนที่, ครบ V1+V2)

วันที่: 2026-10-24
สถานะ: รอ merchant อนุมัติ + sandbox creds (ยังไม่ลงมือจนกว่าจะมีของจริง)

## 1. เป้าหมายและสมมติฐาน

เป้าหมาย: เลิกเรียก SCB ทุกทาง แล้วให้ `IQrPaymentGateway` ตัวเดียวพูดกับ KBank แทน โดย V1 เคาน์เตอร์ (`POST /api/v1/payments/qr`) และ V2 กะ (`POST /api/v2/payments/qr` + attempts/unclaimed/resolve/dismiss) ทำงานเหมือนเดิมทุกประการ หน้าบ้านไม่ต้องแก้เพราะรับแค่ `qrRawData/qrImage/reference/status`

สมมติฐาน (ตรวจจากโค้ดจริงแล้ว):
- Port ไม่ต้องเปลี่ยน: `server/src/modules/qr-payments/applications/ports/qr-payment-gateway.port.ts` มีแค่ `isEnabled/createQr({reference,amountSatang,branchCode})/findPayment({reference,amountSatang,since})` — KBank map ลงได้พอดี
- Core ไม่แตะ: `CreateQrPaymentUseCase`, `CreateQrPaymentV2UseCase`, `QrPaymentRefresher`, `QrPaymentClaims`, `SaleCheckout`, entities, ตาราง `qrPayments/shift_qr_attempts` ใช้ร่วมกันได้
- Web ไม่แตะ: `src/features/pos/api.ts` เรียกแค่ `api.payments.qr.config/post/get/cancel` กับ `apiV2...refresh/cancel/attempts/resolve/unclaimed/dismiss` ไม่รู้จักชื่อธนาคาร; `src/locales/errors.ts` ใช้ code กลาง `QR_*` ไม่มีชื่อ SCB
- ของที่ต้องมีก่อนลงมือ: KBank sandbox `consumerId/secret + client cert/key + merchantId/partnerShopId + baseUrl/tokenUrl + webhook URL ที่ลงทะเบียนแล้ว` — JSON schema จริง capture จาก sandbox หลัง login portal (รีเสิร์ชเจอว่า docs ละเอียดอยู่หลัง login)
