# เลือกและตั้งอุปกรณ์ในร้าน (Windows, Mac, iPad, เครื่อง POS)

ร้านหนึ่งมี **เครื่องหลัก 1 เครื่อง** ที่ติดตั้งระบบและเก็บข้อมูลทั้งหมด ส่วน iPad แท็บเล็ต มือถือ และเครื่อง POS อื่นเป็น **หน้าจอ** ที่เปิดระบบผ่านเบราว์เซอร์ผ่าน Wi-Fi ของร้าน ไม่ต้องติดตั้งโปรแกรมในเครื่องเหล่านั้น

| อุปกรณ์ | ทำหน้าที่ | ทำอะไร |
|---|---|---|
| คอมพิวเตอร์ Windows | เครื่องหลัก หรือหน้าจอ | [เครื่องหลัก Windows](#เครื่องหลัก-windows) |
| Mac | เครื่องหลัก หรือหน้าจอ | [เครื่องหลัก Mac](#เครื่องหลัก-mac) |
| iPad | หน้าจอ | [iPad](#ipad) |
| แท็บเล็ต Android | หน้าจอ | [แท็บเล็ต Android](#แท็บเล็ต-android) |
| เครื่อง POS (Windows หรือ Android) และมือถือ | หน้าจอ | [เครื่อง POS และมือถือ](#เครื่อง-pos-และมือถือ) |

> **สถานะการทดสอบ:** ทดสอบจริงแล้วเฉพาะการติดตั้งบนเครื่องหลัก Windows (สคริปต์หาที่อยู่ LAN เจอ, ระบบตอบผ่านที่อยู่นั้น, ตรวจพบ Wi-Fi แบบ Public และเตือน) ส่วนเครื่องหลัก Mac และการเปิดจาก iPad แท็บเล็ต เครื่อง POS ใช้ขั้นตอนมาตรฐานของระบบปฏิบัติการ แต่ **ยังไม่ได้ลองกับอุปกรณ์จริง** ข้อความที่ยังไม่ยืนยันมีป้าย `[ยังไม่ได้ทดสอบ]` ถ้าติดขัดแจ้งผู้พัฒนาพร้อมข้อความที่เห็นบนจอ

## ก่อนเริ่ม

- เลือกเครื่องหลักที่ **เปิดทิ้งไว้ตลอดเวลาที่ร้านเปิด** และไม่ปิดเองเมื่อไม่มีคนใช้ (ตั้งค่า Sleep เป็น "ไม่เคย" ตอนเสียบปลั๊ก) ถ้าเครื่องหลักหลับหรือปิด เครื่องอื่นในร้านจะเปิดระบบไม่ได้ทั้งหมด
- ทุกเครื่องต้องต่อ Wi-Fi หรือสายแลนของ **ร้านเดียวกัน** อย่าใช้ Wi-Fi แขก (Guest) ที่แยกอุปกรณ์ออกจากกัน
- ตั้งให้เราเตอร์จอง IP ให้เครื่องหลัก (DHCP reservation หรือ Static DHCP ในหน้าตั้งค่าเราเตอร์) ไม่เช่นนั้น IP อาจเปลี่ยนหลังไฟดับ แล้ว iPad จะเปิดที่อยู่เดิมไม่ได้
- ข้อมูลอยู่ที่เครื่องหลักเครื่องเดียว ตั้งเวลาสำรองข้อมูลประจำ (ดู [คู่มือติดตั้ง](install.md#สำรองข้อมูล))

## เครื่องหลัก Windows

1. ทำตาม [คู่มือติดตั้ง](install.md) ด้วย `.\scripts\install.ps1` และตั้งค่าร้านครั้งแรก
2. คลิกขวาที่ PowerShell เลือก **Run as administrator** แล้วรัน `install.ps1` ครั้งที่สอง (ไม่เขียนทับ `.env`) เพื่อให้สคริปต์เปิด firewall ให้เครื่องอื่นเข้าได้ ครั้งแรกไม่ต้องรันด้วยสิทธิ์ผู้ดูแลก็ได้ สคริปต์จะบอกคำสั่งให้
3. จดบรรทัด `Other devices on the same Wi-Fi (iPad, phone): http://192.168.x.x:3000` ที่สคริปต์พิมพ์ นี่คือที่อยู่ที่เครื่องอื่นใช้
4. ถ้า Wi-Fi ของร้านถูกตั้งเป็น **Public** ให้เปลี่ยนเป็น **Private** (Settings → Network & internet → Wi-Fi → ชื่อ Wi-Fi → Network profile type)
5. ตั้ง Sleep เป็น "Never" (Settings → System → Power)
6. หลังรีสตาร์ท Windows ถ้าเครื่องอื่นเปิดระบบไม่ได้ ให้รัน `install.ps1` อีกครั้ง สคริปต์จะเปิด Podman machine และระบบให้ ไม่เขียนทับ `.env` และข้อมูล `[ยังไม่ได้ทดสอบ]` ระบบเริ่มเองอัตโนมัติหลังบูตหรือไม่ ยังไม่ได้ตรวจ

## เครื่องหลัก Mac

`[ยังไม่ได้ทดสอบ]` สคริปต์ยังไม่เคยรันบนเครื่อง Mac จริง

1. ติดตั้ง [Homebrew](https://brew.sh) ถ้ายังไม่มี
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน `scripts/install.sh` (ไม่ต้องใช้ `sudo`) ครั้งแรกจะดาวน์โหลดเครื่องเสมือนประมาณ 1 GB
3. จดบรรทัด `Other devices on the same Wi-Fi (iPad, phone): http://192.168.x.x:3000`
4. ไม่ให้ Mac หลับ: System Settings → Displays → Advanced → "Prevent automatic sleeping on power adapter when the display is off" (ชื่อเมนูต่างกันตามเวอร์ชัน macOS)
5. ถ้าเปิด Firewall ของ Mac ไว้ ให้อนุญาตการเชื่อมต่อขาเข้าของ Podman (System Settings → Network → Firewall)
6. หลังรีสตาร์ท Mac ให้รัน `podman machine start` หรือ `scripts/install.sh` อีกครั้ง

## iPad

1. ต่อ iPad เข้า Wi-Fi ร้านเดียวกับเครื่องหลัก
2. เปิด **Safari** (ใช้ Safari เพราะการเพิ่มลงหน้าจอโฮมบน iPad ทำได้เฉพาะ Safari) พิมพ์ที่อยู่ `http://192.168.x.x:3000` ของเครื่องหลัก หรือเปิดหน้า "ตั้งค่าร้าน" ในเครื่องหลัก เลื่อนไปที่ "เชื่อมต่อ iPad และเครื่องอื่น" แล้วใช้กล้อง iPad สแกน QR
3. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) → **เพิ่มลงในหน้าจอโฮม** → เพิ่ม
4. เปิดจากไอคอน TillumiPOS บนหน้าจอโฮม จะเปิดเต็มจอไม่มีแถบเบราว์เซอร์ แล้วลงชื่อเข้าใช้ตามปกติ
5. ถ้าใช้หน้าแคชเชียร์เป็นหลัก ตั้ง Auto-Lock เป็นเวลานานขึ้น (Settings → Display & Brightness → Auto-Lock) และใช้ Guided Access ถ้าไม่อยากให้พนักงานออกจากแอป `[ยังไม่ได้ทดสอบ]`

ที่อยู่แบบเลข IP ใช้ `http://` เท่านั้น (พอร์ต 3000 ไม่มี HTTPS) ถ้าติดตั้งแบบมีโดเมน ให้ใช้ `https://` ตามโดเมนแทน

## แท็บเล็ต Android

1. ต่อ Wi-Fi ร้านเดียวกับเครื่องหลัก เปิด **Chrome** แล้วพิมพ์ที่อยู่ `http://192.168.x.x:3000` หรือสแกน QR จากหน้า "ตั้งค่าร้าน" ด้วยแอปกล้อง
2. เมนู ⋮ → **เพิ่มลงในหน้าจอหลัก** (Add to Home screen) จะได้ไอคอนทางลัด `[ยังไม่ได้ทดสอบ]`
3. ปุ่ม "ติดตั้งแอป" ของ Chrome ต้องใช้ HTTPS จึงไม่ขึ้นเมื่อเปิดผ่าน `http://` ทางลัดข้อ 2 ใช้งานได้เหมือนกัน ถ้าต้องการให้เปิดเต็มจอแบบแอปจริง ให้ใช้ HTTPS ด้วยโดเมน (ดู [ใช้ผ่านอินเทอร์เน็ตด้วย HTTPS](install.md#ใช้ผ่านอินเทอร์เน็ตด้วย-https))

## เครื่อง POS และมือถือ

เครื่อง POS ที่เป็น Windows ใช้ Chrome หรือ Edge เครื่อง POS ที่เป็น Android และมือถือใช้ Chrome ส่วน iPhone ใช้ Safari ทำเหมือนหัวข้อ iPad หรือ Android ข้างบน หน้าจอปรับตามขนาดอัตโนมัติ (ทดสอบที่ 390, 768 และ 1366 พิกเซล)

- **ใช้ Windows เป็นหน้าจอ:** เปิด Chrome หรือ Edge ไปที่ที่อยู่ของเครื่องหลัก ไม่ต้องรันสคริปต์ติดตั้งในเครื่องนี้ ถ้าอยากได้ไอคอนบนเดสก์ท็อป ใช้เมนูของเบราว์เซอร์ "ติดตั้ง" หรือ "สร้างทางลัด" `[ยังไม่ได้ทดสอบ]` (ปุ่มติดตั้งแอปอาจไม่ขึ้นเมื่อเปิดผ่าน `http://` เลข IP)
- **เครื่องพิมพ์ใบเสร็จ:** ระบบพิมพ์ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์ จึงพิมพ์ได้จากเครื่องที่เสียบหรือเชื่อมเครื่องพิมพ์ไว้ การพิมพ์ใบเสร็จขนาด 58 หรือ 80 มม. ตั้งได้ที่ "ตั้งค่าร้าน" `[ยังไม่ได้ทดสอบ]` การพิมพ์จาก iPad ไปเครื่องพิมพ์ความร้อน

## เปิดไม่ได้ ทำอย่างไร

1. บนเครื่องหลักเอง เปิด `http://localhost:3000` ได้ไหม ถ้าไม่ได้ ระบบยังไม่ทำงาน ดู [แก้ปัญหา](install.md#แก้ปัญหา)
2. เครื่องที่เปิดไม่ได้ ต่อ Wi-Fi เดียวกับเครื่องหลักไหม ปิด Mobile Data บนมือถือด้วย
3. ที่อยู่ถูกต้องไหม IP ของเครื่องหลักอาจเปลี่ยน ดู IP ปัจจุบันด้วย `ipconfig` (Windows) หรือ System Settings → Network (Mac) แล้วจองไว้ที่เราเตอร์
4. Wi-Fi แขก หรือเราเตอร์ที่เปิด "AP Isolation" จะกันไม่ให้อุปกรณ์เห็นกัน ให้ปิดหรือย้ายไปใช้ Wi-Fi หลัก
5. Firewall บนเครื่องหลัก ดูหัวข้อ "เชื่อมต่อเครื่องอื่น" ใน [คู่มือติดตั้ง](install.md#เชื่อมต่อเครื่องอื่น-ipad-มือถือ-เครื่องขายเครื่องที่สอง)
6. หลังอัปเดตระบบ ถ้า iPad ยังแสดงหน้าเก่า ปิดแอปแล้วเปิดใหม่ หรือเปิดใน Safari แล้วรีเฟรช
