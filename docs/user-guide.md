# เริ่มใช้งานที่ร้าน

คู่มือนี้ใช้หลัง [ติดตั้งระบบ](install.md) แล้ว เมนูที่แต่ละคนเห็นขึ้นกับสิทธิ์และความสามารถที่เปิดในตั้งค่าร้าน

## 1. สร้างบัญชีเจ้าของร้าน

เปิดเว็บของเครื่องหลัก ปกติคือ `http://localhost:3000` ถ้ายังไม่มีผู้ใช้ ระบบจะแสดงหน้าตั้งค่าครั้งแรก ใช้รหัสตั้งค่าจากหน้าต่างติดตั้งหรือ log ของแอป แล้วสร้างบัญชีเจ้าของร้าน ไม่มีรหัสผ่านเริ่มต้นให้ใช้ร่วมกัน

ถ้าขึ้นหน้าลงชื่อเข้าใช้ แสดงว่าฐานข้อมูลมีผู้ใช้อยู่แล้ว ให้ใช้บัญชีเดิม การรันตัวติดตั้งซ้ำไม่ได้รีเซ็ตรหัสผ่าน

## 2. ตั้งข้อมูลร้านและสินค้า

1. เข้า **ตั้งค่าร้าน** ตรวจชื่อร้าน ข้อมูลบนใบเสร็จ ภาษี สกุลเงิน เขตเวลา และภาษาหน้าจอให้ตรงกับร้าน
2. เข้า **หมวดหมู่** แล้วเพิ่มกลุ่มสินค้า จากนั้นเข้า **สินค้าและสต็อก** เพื่อเพิ่มสินค้า ราคา และการติดตามสต็อก เว้น SKU ว่างได้ถ้าต้องการให้สร้างอัตโนมัติ
3. ถ้าขายเครื่องดื่ม เปิดใช้ตัวเลือกเสริมในตั้งค่าร้าน แล้วตั้งกลุ่ม เช่น ความหวานหรือท็อปปิง และผูกกับสินค้าที่ใช้
4. สินค้าที่ติดตามสต็อกต้องมีจำนวนก่อนขาย ใช้ **ใบรับสินค้าเข้า** สำหรับของที่รับเพิ่ม หรือปรับยอดให้ตรงกับการนับจริง
5. เพิ่มพนักงานและกำหนดสิทธิ์ในหน้า **ผู้ใช้** ให้แต่ละคนใช้บัญชีของตัวเอง

ระบบมีสาขา `MAIN` เดียว ไม่ต้องสร้างหรือสลับสาขา หากใช้โต๊ะ เปิดความสามารถโต๊ะในตั้งค่าร้าน แล้วจัดโต๊ะก่อนรับออเดอร์ ไม่มีระบบส่งครัว

## 3. เปิดกะและขาย

ร้านใหม่ที่ติดตั้งผ่านสคริปต์ใช้โหมดกะ (`shifts`) เข้า **กะและลิ้นชักเงินสด** เลือกหรือสร้างจุดขายตามสิทธิ์ แล้วเปิดกะพร้อมกรอกเงินตั้งต้น จากนั้นไปหน้าขาย

1. ค้นหาหรือสแกนสินค้า เลือกตัวเลือกและจำนวน ตรวจรายการในตะกร้า
2. เลือกสมาชิกหรือส่วนลดเมื่อจำเป็น แล้วตรวจยอดสุทธิ
3. เลือกวิธีชำระ ถ้าเป็นเงินสด กรอกยอดรับเพื่อคำนวณเงินทอน
4. ถ้าใช้ QR พร้อมเพย์ที่กำหนดผู้รับไว้ ให้ตรวจยอดเงินเข้าในธนาคารก่อนกดยืนยัน การเห็น QR หรือหลักฐานที่ลูกค้าแสดงยังไม่ใช่การตรวจสถานะจากธนาคาร
5. หลังขายสำเร็จ เปิดรายละเอียดบิลเพื่อพิมพ์หรือบันทึก PDF

การชำระด้วย SCB QR มีขั้นตอนตรวจสถานะจากธนาคารแยก ต้องตั้งค่าและทดสอบก่อนใช้ ส่วนบัตรเป็นการบันทึกช่องทางชำระ ไม่มีการสั่งเครื่องรูดบัตร

ถ้าหน้ากะแจ้งว่าอยู่โหมดเดิม (`legacy`) ให้ผู้ดูแลอ่าน [คู่มือเปลี่ยนโหมดกะ](cash-shift-cutover.md) ก่อนแก้ค่า ไม่ต้องเปิดกะสำหรับการขายในโหมดเดิม

## 4. เก็บออเดอร์ไว้จ่ายทีหลัง

ใช้การพักเป็นออเดอร์เมื่อลูกค้ายังไม่ชำระ เปิดออเดอร์นั้นมาทำต่อได้ หรือผูกกับโต๊ะเมื่อเปิดใช้โต๊ะ ราคาในรายการถูกเก็บไว้ตอนเพิ่มรายการ สต็อกจะตรวจและตัดเมื่อชำระ ไม่ได้จองไว้ตอนรับออเดอร์

ระบบมีการย้ายโต๊ะ รวมออเดอร์ และแยกตามรายการ ตรวจรายการกับยอดทุกครั้งก่อนชำระ หมายเหตุ เช่น "ไม่ใส่น้ำตาล" เก็บกับรายการได้ แต่ไม่ได้ส่งไปจอครัว

## 5. จบกะและเก็บสำรอง

บันทึกเงินเข้าออกที่ไม่ใช่ยอดขายพร้อมเหตุผล ก่อนจบกะตรวจรายการรับเงิน โดยเฉพาะ QR ที่สถานะยังไม่ชัดเจน จากนั้นเริ่มนับเงิน กรอกยอดที่นับจริงและเหตุผลหากต่างจากยอดคาดหมาย แล้วปิดกะ

ดูยอดย้อนหลังได้จากหน้ารายงานตามสิทธิ์ รายงานยอดขายใช้สถานะบิลปัจจุบัน ส่วนรายงานปิดกะเก็บยอด ณ ตอนนับ จึงอาจต่างกันเมื่อมีการยกเลิกบิลภายหลัง ดู [นิยามรายงาน](sales-reports.md)

สำรองด้วย `scripts/backup.ps1` และคัดลอกไฟล์ออกนอกเครื่องหลักด้วย ดู [วิธีสำรองและกู้คืน](install.md#สำรองข้อมูล) ควรลองกู้คืนในระบบแยกก่อนต้องใช้ไฟล์จริง

## ถ้ามีปัญหาระหว่างขาย

| อาการ | ควรทำอย่างไร |
|---|---|
| พิมพ์ไม่ออกหลังชำระ | ตรวจบิลเดิมก่อน อย่าขายซ้ำเพื่อพิมพ์ใหม่ ใช้ PDF หรือพิมพ์ผ่านเบราว์เซอร์ และดู [คู่มือเครื่องพิมพ์](thermal-printer-setup.md) |
| QR ค้างหรือไม่รู้ผล | ตรวจ/รีเฟรชสถานะผ่านระบบตามโหมดที่ใช้ อย่าสร้างรายการใหม่โดยถือว่าอันเดิมไม่สำเร็จ |
| ไม่เห็นเมนูบางหน้า | ให้เจ้าของตรวจสิทธิ์ของผู้ใช้และความสามารถที่เปิดในตั้งค่าร้าน |
| แท็บเล็ตเข้าไม่ได้ | ตรวจว่าเครื่องหลักเปิดอยู่และไม่หลับ แล้วทำตาม [คู่มืออุปกรณ์](devices.md#เปิดไม่ได้-ทำอย่างไร) |
| เว็บว่างหรือขึ้น error | รีโหลดหน้า หากยังเป็น ให้เก็บข้อความ Console และ log ของแอปตาม [แก้ปัญหา](install.md#แก้ปัญหา) โดยปิดบังรหัสผ่าน รหัสตั้งค่า และ token ก่อนส่ง |
