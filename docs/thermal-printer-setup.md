# ตั้งค่าเครื่องพิมพ์ใบเสร็จผ่านแลน (LAN/WiFi)

ระบบสั่งพิมพ์ตรงไปเครื่องพิมพ์ความร้อนที่ต่อสายแลนหรือ Wi-Fi ร้าน ตัวหนังสือไทยพิมพ์เป็นภาพ (ร้านทุกรุ่นพิมพ์ตรงกัน ไม่ต้องลุ้นภาษาไทยเพี้ยน) พิมพ์เสร็จตัดกระดาษเอง และเตะลิ้นชักให้ถ้าเสียบไว้

> **ขอบเขตรอบนี้:** ใช้ได้เฉพาะเครื่องพิมพ์ที่มีช่องต่อ **LAN (สาย) หรือ Wi-Fi** เท่านั้น ยังไม่รองรับ USB และ Bluetooth ถ้าร้านมีแต่เครื่องแบบ USB ให้พิมพ์ผ่านปุ่มบันทึก PDF หรือหน้าต่างพิมพ์ของเบราว์เซอร์ไปก่อนได้เหมือนเดิม

> **สถานะการทดสอบ:** ขั้นตอนในคู่มือนี้ผ่านเทสต์อัตโนมัติด้วยเครื่องพิมพ์จำลองแล้ว แต่ **`[ยังไม่ได้ทดสอบ]` กับเครื่องพิมพ์จริง** ถ้าติดขัดแจ้งผู้พัฒนาพร้อมข้อความที่เห็นบนจอ

## ของที่ต้องมี

- เครื่องพิมพ์ความร้อนที่มีพอร์ต LAN (RJ45) หรือ Wi-Fi ดูด้านหลังเครื่องว่ามีช่องเสียบสายแลนไหม
- กระดาษม้วน **58 หรือ 80 มม.** ให้ตรงกับที่ตั้งในระบบ (ดูข้อ 5)
- ลิ้นชักที่ใช้สาย RJ11 (สายโทรศัพท์หัวใหญ่) เสียบเข้าพอร์ต `DRAWER`/`DK` หลังเครื่องพิมพ์ ถ้าร้านมี

## ตารางรุ่นที่ร้านนิยม

| รุ่น | วิธีเช็คว่ามี LAN |
|---|---|
| Epson TM-T20III / TM-T82III (รุ่นย่อยที่มี Ethernet) | ดูสเป็กรุ่นย่อยว่ามีคำว่า Ethernet/LAN และดูช่อง RJ45 หลังเครื่อง `[ยังไม่ได้ทดสอบ]` |
| XPrinter รุ่นที่มี LAN (เช่น ตระกูล XP-Q200) | ดูสเป็กรุ่นย่อยว่ามี LAN และดูช่อง RJ45 หลังเครื่อง `[ยังไม่ได้ทดสอบ]` |
| Sewoo / Bixolon รุ่นที่มี LAN | วิธีเดียวกัน ดูช่อง RJ45 หลังเครื่อง `[ยังไม่ได้ทดสอบ]` |

รุ่นย่อยต่างกันมีหรือไม่มี LAN ต่างกันได้ วิธีชัวร์ที่สุดคือพิมพ์ **self-test** ตามข้อ 2 แล้วดูว่ามีบรรทัด IP address ออกมาหรือไม่

## ขั้นตอน

### 1. ต่อเครื่องพิมพ์เข้าเครือข่ายร้าน

- แบบสาย: เสียบสายแลนจากเครื่องพิมพ์ไปเราเตอร์/สวิตช์ตัวเดียวกับเครื่องหลัก
- แบบ Wi-Fi: ตั้งค่า Wi-Fi ในเครื่องพิมพ์ตามคู่มือของรุ่นนั้น ให้เกาะ **Wi-Fi หลักของร้าน** ห้ามใช้ Wi-Fi แขก (Guest) เพราะเราเตอร์กันไม่ให้อุปกรณ์เห็นกัน

### 2. หา IP ของเครื่องพิมพ์ (self-test)

`[ยังไม่ได้ทดสอบ]` วิธีทั่วไป (ถ้าไม่ได้ผล ดูคู่มือของรุ่นนั้น):

1. ปิดเครื่องพิมพ์
2. กดปุ่ม **FEED** ค้างไว้แล้วเปิดเครื่อง รอประมาณ 3 วินาทีแล้วปล่อย
3. เครื่องจะพิมพ์กระดาษออกมา มีบรรทัด `IP address` เช่น `192.168.1.50` นั่นคือที่อยู่ของเครื่องพิมพ์ จดไว้

### 3. จอง IP ไว้ที่เราเตอร์ (สำคัญ)

ถ้าไม่จอง หลังไฟดับเราเตอร์อาจแจก IP ใหม่ให้เครื่องพิมพ์ แล้วระบบจะพิมพ์ไม่ออกโดยไม่มีอะไรเสีย:

1. เปิดหน้าเว็บของเราเตอร์ (ปกติ `http://192.168.1.1` ดูรหัสหลังเราเตอร์)
2. หาเมนู **DHCP Reservation**, **Static DHCP** หรือ **Address Reservation**
3. จอง IP เดิม (ข้อ 2) ให้เครื่องพิมพ์ (เลือกจากชื่อรุ่นหรือ MAC address ที่พิมพ์บน self-test)

ถ้าทำไม่เป็น ให้ช่างเน็ตหรือคนขายเครื่องพิมพ์ทำให้ครั้งเดียว จบแล้วไม่ต้องทำอีก

### 4. เสียบลิ้นชัก (ถ้ามี)

เสียบสาย RJ11 ของลิ้นชักเข้าพอร์ต `DRAWER` หรือ `DK` หลังเครื่องพิมพ์ ไม่ใช่พอร์ต LAN

### 5. ตั้งค่าในระบบ

เปิดระบบในเครื่องหลัก ไปที่ **ตั้งค่าร้าน** เลื่อนลงไปที่ **เครื่องพิมพ์ใบเสร็จ (แลน)**:

1. **ขนาดกระดาษ** เลือกให้ตรงม้วนที่ใส่ (58 หรือ 80 มม.) ถ้าเลือกผิดใบจะออกมาแคบหรือกว้างเกิน
2. **IP เครื่องพิมพ์** กรอก IP จากข้อ 2 (เช่น `192.168.1.50`)
3. **พอร์ต** ปกติคือ `9100` เปลี่ยนเฉพาะเมื่อตั้งเครื่องพิมพ์ไว้เป็นอื่น
4. เปิด **พิมพ์ผ่านแลน** (ถ้ายังไม่กรอก IP จะเปิดไม่ได้)
5. ถ้าเสียบลิ้นชักไว้ เปิด **เปิดลิ้นชักหลังพิมพ์**
6. กด **บันทึก**

### 6. พิมพ์ใบทดสอบ

1. เปิดบิลขายจริง 1 ใบ (ขายของจริงหรือบิลทดสอบก็ได้)
2. ในหน้ารายละเอียดบิล กด **พิมพ์ใบเสร็จ (LAN)** ปุ่มจะอยู่ข้างปุ่มบันทึก PDF
3. ใบต้องออกมา ตัวหนังสือไทยครบสระบนล่าง ตัดกระดาษเอง และลิ้นชักเปิด (ถ้าเปิดไว้)
4. ลองทั้งม้วน 58 และ 80 ถ้าร้านมีสองขนาด (อย่าลืมเปลี่ยนขนาดกระดาษในตั้งค่าร้านให้ตรงม้วนก่อนพิมพ์)

ถ้าพิมพ์ไม่สำเร็จ หน้าจอจะบอกเหตุผลเป็นภาษาไทย และ**บิลไม่หาย** (บิลขายสำเร็จไปแล้วตั้งแต่ก่อนพิมพ์) ให้พิมพ์ผ่านปุ่ม PDF หรือเบราว์เซอร์แทน แล้วแก้ตามตารางด้านล่าง

## เปิดไม่ได้ ทำอย่างไร

| อาการ | สาเหตุที่พบบ่อย | วิธีแก้ |
|---|---|---|
| `เชื่อมต่อเครื่องพิมพ์ไม่ได้` | เครื่องพิมพ์ปิดอยู่ / อยู่คนละวงแลน / IP ผิด | เปิดเครื่องพิมพ์ ต่อ Wi-Fi/สายวงเดียวกับเครื่องหลัก แล้วเช็ค IP ด้วย self-test อีกครั้ง |
| `เชื่อมต่อเครื่องพิมพ์ไม่ได้` ทั้งที่ IP ถูก | Wi-Fi แขกหรือ AP Isolation กันอุปกรณ์ | ย้ายเครื่องพิมพ์และเครื่องหลักไป Wi-Fi หลักของร้าน ปิด AP/Client Isolation ที่เราเตอร์ |
| `เชื่อมต่อเครื่องพิมพ์ไม่ได้` เฉพาะเครื่องหลักเครื่องนี้ | Firewall กันขาออก | ปกติ Windows ปล่อยขาออกอยู่แล้ว ถ้ามีโปรแกรมกันไว้ ให้เปิดทางออก TCP พอร์ต 9100 ไป IP เครื่องพิมพ์ |
| `เครื่องพิมพ์ตอบช้าเกินไป` | การเชื่อมต่อหรือส่งข้อมูลค้าง | ตรวจเครื่องพิมพ์ก่อนสั่งซ้ำ อาจมีข้อมูลส่งไปแล้วแม้ระบบแจ้ง error ถ้าต้องพิมพ์ใหม่ให้ใช้บิลเดิม และตรวจว่าไม่ได้ออกซ้ำ |
| ใบออกครึ่งใบแล้วหยุด | กระดาษยัดหรือไฟตกตอนพิมพ์ | ตรวจและแก้ที่เครื่องพิมพ์ก่อน การสั่งใหม่อาจออกทั้งใบซ้ำ ใช้บิลเดิมโดยไม่ทำรายการขายใหม่ |
| ตัวหนังสือเพี้ยน สระหาย | ไม่ควรเกิด (ระบบส่งเป็นภาพ) | ถ้าเกิด ถ่ายรูปใบ + แจ้งผู้พัฒนา แล้วใช้ปุ่ม PDF ไปก่อน |
| ใบแคบ/กว้างผิดปกติ | ขนาดกระดาษในตั้งค่าร้านไม่ตรงม้วน | เปลี่ยน 58/80 ในตั้งค่าร้านให้ตรงม้วนแล้วพิมพ์ใหม่ |
| ลิ้นชักไม่เปิด | สายหลุด / ลืมเปิดสวิตช์ | เสียบ RJ11 ให้แน่น เปิด **เปิดลิ้นชักหลังพิมพ์** ในตั้งค่าร้านแล้วบันทึก |
| เคยพิมพ์ได้ หลังไฟดับพิมพ์ไม่ได้ | เราเตอร์แจก IP ใหม่ | จอง IP ตามข้อ 3 แล้วกรอก IP ใหม่ในตั้งค่าร้าน |

## เรื่องควรรู้

- การตั้งค่าเครื่องพิมพ์อยู่ในฐานข้อมูลของร้าน **สำรองและกู้คืนกลับมาพร้อมกัน** (ดู[คู่มือติดตั้ง](install.md#สำรองข้อมูล))
- ยังไม่มีโลโก้ร้านบนใบเสร็จรอบนี้
- รูปสินค้า (R2/อัปโหลด) ไม่เกี่ยวกับใบเสร็จ
- ปุ่มบันทึก PDF และพิมพ์ผ่านเบราว์เซอร์ยังอยู่ ใช้แทนกันได้ตลอด
- ระบบจำผลการส่งที่สำเร็จด้วยคีย์ของคำสั่ง แต่ยังรับรองไม่ได้ว่ากระดาษออกครบหรือไม่ซ้ำเมื่อส่งค้าง หรือกดจากหลายเครื่องพร้อมกัน
