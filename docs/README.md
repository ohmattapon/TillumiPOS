# คู่มือ TillumiPOS

ถ้าเพิ่งดาวน์โหลดระบบ เริ่มจากติดตั้งบนเครื่องหลัก แล้วสร้างบัญชีเจ้าของร้านก่อนเพิ่มสินค้าหรือเริ่มขาย ไม่มีบัญชีและรหัสผ่านเริ่มต้นสำหรับร้านค้า

## สำหรับคนใช้ที่ร้าน

| ต้องการทำอะไร | อ่านที่นี่ |
|---|---|
| ดูฟังก์ชันและข้อจำกัด | [ภาพรวมระบบ](summary.md) |
| ติดตั้ง เปิดระบบ อัปเดต สำรอง หรือกู้คืน | [คู่มือติดตั้ง](install.md) |
| ตั้งค่าร้านและเริ่มขาย | [คู่มือเริ่มใช้งาน](user-guide.md) |
| ใช้มือถือ แท็บเล็ต หรือเครื่องขายเพิ่ม | [ตั้งอุปกรณ์ในร้าน](devices.md) |
| ตั้งเครื่องพิมพ์ใบเสร็จผ่าน LAN | [เครื่องพิมพ์ใบเสร็จ](thermal-printer-setup.md) |
| เข้าใจตัวเลขยอดขายและกำไร | [รายงานยอดขาย](sales-reports.md) |
| ย้ายร้านเดิมไปใช้การเปิดและปิดกะ | [เปลี่ยนเป็นโหมดกะ](cash-shift-cutover.md) |

## สำหรับคนพัฒนาต่อหรือดูแลเซิร์ฟเวอร์

- [README หลัก](../README.md#รันเพื่อพัฒนา): เตรียมเครื่องพัฒนา คำสั่ง และการทดสอบ
- [Cloudflare](cloudflare.md): ติดตั้งบนคลาวด์ ต้องเตรียมบริการและค่าใช้จ่ายแยก
- [Redis cache](redis-cache.md): cache เสริม ไม่ใช่ฐานข้อมูลหลัก
- [Pagination](pagination.md): รูปแบบการแบ่งหน้าของ API
- [ข้อมูลสินค้าสาธิต](demo-product-catalog.md): ที่มาและเงื่อนไขการใช้ข้อมูล
- [AGENTS.md](../AGENTS.md): กติกาโครงสร้างโค้ดและการทำงานใน repository

คู่มือชุดนี้อิง main ที่ตรวจเมื่อ 20 ตุลาคม 2026 งาน Tauri และตัวติดตั้ง native ที่อยู่ branch อื่นยังไม่ใช่เส้นทางติดตั้งในคู่มือชุดนี้

`superpowers/specs/`, `superpowers/plans/`, `work-log-*` และเอกสารแผนปรับ UI เป็นประวัติ/แผนงาน อ่านประกอบการพัฒนาได้ แต่ไม่ควรใช้แทนขั้นตอนติดตั้งปัจจุบัน
